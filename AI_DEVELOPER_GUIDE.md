# ECLYPSIA — AI Developer Guide

## Project
Create a 3D anime-inspired open-world RPG for Android using Godot 4 and GDScript.

## Rules
- Inspect existing files before changing anything.
- Preserve working code and assets.
- Make small, testable improvements.
- Never claim a feature works unless it has been tested.
- Optimize for Android performance.
- Never commit API keys, passwords, or tokens.

## Development roadmap
1. Create a valid Godot 4 project.
2. Implement third-person movement and camera.
3. Add mobile touch controls.
4. Build a test arena.
5. Implement sword combat and magic.
6. Add UI, animations, and visual effects.
7. Test performance and Android compatibility.
8. Expand the open world after the core gameplay works.

## Testing
Run Godot headless checks whenever possible.
If Godot cannot be launched, report that runtime testing was not performed.
Never fabricate test results.
